# ⚡ ReviewPulse AI — Executive Web Dashboard

This directory contains the production-grade React + Vite web dashboard for **ReviewPulse AI**.

## 🎨 Architecture & Stack
- **Framework**: React 19 + Vite 6
- **Design System**: Demostack Executive Light Theme (Warm Luminous Aesthetic)
- **Typography**: Plus Jakarta Sans, Newsreader Italic Serif, Inter, JetBrains Mono
- **Visual Telemetry**: Real-time KPI counters, sentiment distribution donuts, and Pareto ranking bars
- **Dual Display Modes**: Fluid Card Grid and Dense Table views with one-click CSV export

## 🚀 Development Quick Start
```bash
npm install
npm run dev
```

The application will be accessible at `http://localhost:5173`.
